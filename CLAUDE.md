## Architecture

Personal tech blog in Serbian (Latin script), no database or CMS: content is MDX files in the repo.

- **Posts** live in `src/content/posts/<slug>.mdx` with YAML frontmatter (`title`, `description`, `date` as `YYYY-MM-DD`, `draft`, optional `image` path under `public/` and `tags` array; reading time is computed). The file name is the URL slug (`/blog/<slug>`). Adding a post = adding a file; nothing else needs to change. `draft: true` hides it everywhere.
- `src/lib/posts.ts` reads frontmatter with `gray-matter` via sync `fs` (predictable, so it's in the static shell without `"use cache"`). Pages render MDX via `@next/mdx` (`remark-gfm`, `remark-frontmatter` as string plugins for Turbopack) with dynamic `import(\`@/content/posts/${slug}.mdx\`)`.
- Routes: `/` (video hero + card grid of 8 latest, `PostGrid`), `/blog`, `/blog/[slug]`, `/o-meni` (content in `src/content/o-meni.mdx`), `/rss.xml`, `/sitemap.xml`, `/robots.txt`. Site name/URL in `src/lib/site.ts` (`NEXT_PUBLIC_SITE_URL` env var).
- Unknown slugs use `notFound()`; every `[slug]` must come from `generateStaticParams` (static export).
- MDX prose styled with `@tailwindcss/typography` (`prose dark:prose-invert`).

- **App Router** under `src/app/`. Import alias `@/*` → `src/*`.
- **Static export for GitHub Pages** (`output: "export"`, `trailingSlash: true`, `images.unoptimized`) in `next.config.ts`; `cacheComponents` is off because it conflicts with export route handlers. No server at runtime: no Server Actions, cookies, request-dependent route handlers or image optimization. Route handlers / metadata routes need `export const dynamic = "force-static"`.
- **basePath**: deployed at `https://radislavlazarevic.github.io/sajt-sa-blogom`, so `.github/workflows/deploy.yml` sets `NEXT_PUBLIC_BASE_PATH` and `NEXT_PUBLIC_SITE_URL`. `<Link>` adds the prefix itself; plain `src`/`href` to files in `public/` and `next/image` `src` must go through `withBasePath()` from `src/lib/site.ts`. Deploys on every push to `main`.
- **Newsletter** form posts from the browser to Formspree (`NEXT_PUBLIC_FORMSPREE_ID`, set as repo variable `FORMSPREE_ID`).
- **Tailwind CSS v4** is wired through Turbopack's `@tailwindcss/turbopack` loader (configured under `turbopack.rules` in `next.config.ts`), not PostCSS — there is no `postcss.config` or `tailwind.config`. Theme tokens live in `src/app/globals.css` via `@import "tailwindcss"` and `@theme inline`; light/dark colors are CSS variables switched with `prefers-color-scheme`.
- Route prop types use Next's generated global helpers (e.g. `LayoutProps<"/">`, `PageProps<...>`) rather than hand-written prop interfaces.
- Fonts: Geist / Geist Mono via `next/font/google`, exposed as `--font-geist-sans` / `--font-geist-mono`.
